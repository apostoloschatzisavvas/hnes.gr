# hnes.gr

Ο ιστότοπος της Ελληνικής Κοινότητας Πυρηνικής Ενέργειας (ΕΚΠΕ) · The website of the Hellenic Nuclear Energy Society (HNES).

## Άρθρα στο Κέντρο Γνώσης

Τα μέλη του ΔΣ γράφουν άρθρα στο **https://hnes.gr/admin/**, με σύνδεση μέσω GitHub.

1. Πατήστε «Νέο άρθρο».
2. Συμπληρώστε τίτλο, διεύθυνση σελίδας (λατινικά), περίληψη και κείμενο. Η εικόνα και το PDF είναι προαιρετικά.
3. Πατήστε «Αποθήκευση». Σε 1–2 λεπτά το άρθρο εμφανίζεται στο site.

Για αγγλική εκδοχή, ενεργοποιήστε τα αγγλικά από την επιλογή γλώσσας μέσα στο άρθρο. Για να γίνει κάποιος συντάκτης, χρειάζεται δωρεάν λογαριασμό GitHub και πρόσκληση σε αυτό το repository.

## Πώς είναι οργανωμένο

| Φάκελος | Τι περιέχει |
|---|---|
| `site/` | Το έτοιμο site. Δεν αλλάζει με το χέρι. |
| `templates/` | Τα πρότυπα της σελίδας άρθρου. |
| `content/articles/` | Τα άρθρα, ένα αρχείο ανά άρθρο και γλώσσα (`<slug>.el.md`, `<slug>.en.md`). |
| `content/media/` | Εικόνες και PDF των άρθρων. |
| `admin/` | Ο επεξεργαστής άρθρων (Sveltia CMS). |
| `build.py` | Συνθέτει το site με τα άρθρα στον φάκελο `public/`. |

Το Netlify τρέχει το `build.py` σε κάθε αλλαγή και δημοσιεύει τον φάκελο `public/`. Τοπικά:

```bash
pip install -r requirements.txt
python3 build.py
```
